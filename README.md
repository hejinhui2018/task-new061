# CaptionFlow · 字幕时间轴校对台

多人协作字幕流程中，编辑各自修改时间轴容易导致整体漂移、说话人标签错位。CaptionFlow 提供一个纯前端的校对台：导入带时间码和说话人的片段，按语言查看，拖动/拆分片段，实时检测问题并预览每次调整的影响。

## 功能

- **多语言查看**：语言标签页切换，时间轴与列表同步显示对应译文
- **时间轴编辑**：拖动片段（100ms 吸附）、中点拆分（文本按时间比例分配）、表格内直接改时间码/说话人/译文
- **问题检测**：时间重叠、空白（阈值可调）、说话人冲突（同一说话人时间相交）、翻译超时（译文阅读速度超过字/秒上限）
- **影响预览**：插入延迟 / 批量平移 / 重叠修复在应用前实时显示「调整前 → 调整后」的问题增减与受影响片段
- **连锁平移**：插入延迟自动带动其后所有片段，相对间隔保持不变
- **撤销/重做**：全部编辑操作可撤销（Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z），上限 100 步
- **版本快照**：任意时刻存快照，两两对比差异（平移/时长/说话人/文本），一键回滚（可撤销）
- **刷新恢复**：文档与版本自动写入 localStorage，刷新后原样恢复并提示
- **导入导出**：JSON（毫秒或时间码均可）与 SRT（支持「说话人: 文本」前缀）导入；JSON / 当前语言 SRT 导出

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm test         # Vitest（64 个用例）
npm run build    # tsc --noEmit && vite build
```

## 架构

`src/core/` 为纯函数领域层，不依赖 React，全部可注入测试：

| 模块 | 职责 |
| --- | --- |
| `timecode.ts` | 毫秒 ↔ `HH:MM:SS,mmm` 解析与格式化 |
| `operations.ts` | 连锁平移、批量平移、拖动、拆分、重叠修复等片段操作 |
| `issues.ts` | 重叠 / 空白 / 说话人冲突 / 翻译超时检测 |
| `impact.ts` | 操作预览：前后问题对比、新增/解决问题、受影响片段 |
| `history.ts` | 通用撤销/重做栈（带操作标签与容量上限） |
| `versions.ts` | 版本快照（深拷贝）与版本间 diff |
| `storage.ts` | 会话持久化（`StorageLike` 接口，测试用内存实现） |
| `clock.ts` | 可注入时钟，版本时间/保存时间可确定性测试 |
| `sample.ts` | 内置双人采访示例（中英双语） |
| `importers.ts` | JSON / SRT 导入与 SRT 导出 |

UI 层（`src/App.tsx` + `src/components/`）只负责状态分发与渲染，所有时间码计算都在核心层完成。测试覆盖相邻边界、连锁平移、重叠修复、版本恢复等关键场景（`src/core/*.test.ts`）。
